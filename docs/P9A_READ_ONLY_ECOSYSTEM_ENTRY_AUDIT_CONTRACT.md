# 南枫 AI P9-A 最小只读生态入口审计合同

日期：2026-08-13  
状态：合同与现状审计完成；**没有生态应用接入，P9 的真实只读闭环尚未开始。**

## 唯一目标、所有者与范围

本轮只核验 P9 的首个候选是否存在可验证的、稳定且最小授权的公开只读入口。总蓝图的默认优先候选为“南枫知识库”；目标应用继续拥有其业务数据、Provider Framework 和任何未来跨应用入口。南枫 AI 的唯一职责仅是保存本次审计结论；它不拥有也不解释目标应用内部数据库、文件或业务规则。

允许范围：查看南枫 AI 当前代码/文档，以及本机可见的目标应用**参考工程的公开文档和项目规则**。禁止读取目标应用数据库、用户文件、私有配置或运行状态；禁止网络、Provider、Key、跨应用写入、高风险动作、模拟器安装/清数据、OPPO 或 Windows 操作。

## 已确认差距与停止条件

1. 没有可在当前 Mac 上审计的南枫知识库实际源码、已安装应用公开入口或用户授予的最小读取授权；参考快照不能证明真实产品的 API、版本、权限、可用性或数据保留状态。
2. 因而无法建立 P9 所要求的“来源、权限、预览、目标应用确认、结果回读、撤销和审计”中的任何真实跨应用链路；尤其不能从 Tauri 内部 Repository、SQLite 或历史导入导出能力推断为对外授权。
3. 在以下任一条件满足前停止，不创建 Android/desktop adapter、协议 DTO、manifest query、IPC、数据库迁移、测试夹具或 UI：用户指定一个稳定目标应用公开入口，或提供该目标应用可审计的正式源码/已安装入口及明确的最小只读授权。

## 未来重新启动 P9-A 所需的最小输入

- 目标应用的精确身份、版本与其拥有者声明的公开入口；
- 版本化只读 schema：稳定 ID、允许读取的摘要字段、来源/时间/版本与不支持状态；
- 最小权限的授予、暂停/撤销与失效语义；
- 南枫 AI 的只读预览与不持久化/不写入边界；
- 目标应用确认、结果回读、审计最小化与取消/重放行为。

以上输入到位后，仍须先新建“一个目标应用、一个只读 Adapter”的独立实施合同；写入、导入内部数据库、Provider/网络、Key 或高风险动作不由本合同授权。

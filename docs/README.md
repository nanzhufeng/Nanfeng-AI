项目名称：南枫 AI

定位：
个人多模型 AI 工作台。

核心规则：
1. 每个南枫软件拥有自己的 AI Provider Framework。
2. 南枫 AI Hub 是可选增强层，不是基础依赖。
3. 数据默认本地保存，可导出。
4. 不绑定单一模型厂商。
5. 所有模型调用、Token、费用可追踪。

支持方向：
ChatGPT、Claude、DeepSeek、Qwen、Kimi 等多模型统一入口。

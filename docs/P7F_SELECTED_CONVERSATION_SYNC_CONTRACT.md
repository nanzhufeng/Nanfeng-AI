# P7-F 手动选择对话同步合同

状态：Android 本地实现、Google Cloud OAuth 配置与 JVM/Build 回归完成；真实账号登录、密文同步与跨设备恢复尚未验收。

## 产品边界

- 普通对话和工作对话的长按菜单提供“同步到南枫云”。已完成登录与恢复保护时，点击后直接同步该对话，不再叠加二次确认弹窗。
- 只有云端提交并回读校验成功后，才会写入本机“已手动同步”记录。登录、预检或失败不会扩大选中范围。
- 设置 → 数据管理 → Google 账号与同步中的“定期同步”由用户手动开启，每 12 小时只更新当前账号曾经手动同步成功的对话。它不扫描其他对话，也不同步记忆、项目、知识、设置或其他本机数据。
- 退出登录会取消定期工作，不删除本机对话或手动选择记录；同一账号重新登录且恢复保护就绪后，才能恢复已开启的定期工作。

## 数据与安全

- 每份云端文档只包含一条明确对话的文本消息树和最小会话元数据。含附件、工具结果或未完成草稿的对话整体拒绝上传，不做用户无法识别的部分同步。
- 文档 ID 由对话 ID 哈希派生；业务内容在本机加密后才交给云端。Google ID Token 只用于换取 Supabase 会话，访问／刷新令牌使用 Android Keystore 保护。
- 恢复码明文不持久化。首次确认后只保留经恢复码派生、并由 Keystore 加密的本机包装材料，用于之后的直接与定期同步。
- 云端已存在但本机没有匹配回执，或修订号／密文哈希不一致时，必须停在冲突，不覆盖未知云端版本。

## 界面

- 账号页复用南枫 AI 现有白卡、字体、圆角、主题色、共享开关和点外关闭规则，分为身份、账号管理、对话同步三区，不新建独立视觉风格。“切换 Google 账号”和“退出登录”在账号管理白卡内使用同一灰色填充底、无描边、同轮廓与同反馈，不使用白底描边按钮。
- 账号入口位于设置“数据管理”首行；对话入口只位于既有长按菜单，不在 Composer 新增常驻按钮。

## 未完成的真实验收

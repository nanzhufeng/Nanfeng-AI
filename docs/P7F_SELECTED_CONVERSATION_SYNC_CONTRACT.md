# P7-F 手动选择对话同步合同

状态：跨端同步行为合同；动态测试、正式安装与真实服务证据见 [当前交接](CURRENT_HANDOFF.md)，不得用构建或回执代替全文一致性验收。

## 产品边界

- 普通对话和工作对话的长按菜单提供“同步到南枫云”。已完成 Google 登录时，点击后直接同步该对话，不再叠加二次确认弹窗。
- 只有云端提交并回读校验成功后，才会写入本机“已手动同步”记录。登录、预检或失败不会扩大选中范围。
- 设置 → 数据管理 → Google 账号与同步中的“定期同步”由用户手动开启，每 12 小时只更新当前账号曾经手动同步成功的对话。它不扫描其他对话，也不同步记忆、项目、知识、设置或其他本机数据。
- 退出登录会取消定期工作，不删除本机对话或手动选择记录；同一账号重新登录后，才能恢复已开启的定期工作。
- 已选同步身份不随列表展示或工作区切换而改变；后续正文与标题修改仍属于该对话的续同步。Android 持久化变更调度已选对话；Desktop 普通回复及重试落库后触发已选对话同步。后台退出、补账与网络中断的实际恢复另行验收。

## 数据与安全

- 每份云端文档只包含一条明确对话的文本消息树、会话元数据及回答原模型/用量/金额。附件字节和工具运行块不传输，但不能因此丢弃同条消息正文或后续完整回答；本机附件与运行记录保留。未完成草稿不外发。
- 用户于 2026-09-18 明确选择取消恢复码和端到端加密。当前写入格式为 `nfai.sync.direct`，采用 Google 登录、HTTPS、Supabase `auth.uid()` 账号隔离及文档 CAS；服务端可以读取会话正文。hash 用于内容校验，不代表加密或身份认证。账号令牌仍保存在平台私有凭据存储。
- 新设备登录后直接读取／同步，不创建、输入、确认或轮换恢复码。历史 `nfai.sync.envelope` 仅保留读取兼容；既有私有包装材料不得提前删除。
- 2026-09-18 后续澄清：用户接受删除今后不再需要的恢复码功能，条件是不能留下隐藏的恢复码卡点。Google 登录的账号状态机不得创建、读取或检查加密密钥来决定 direct 同步资格；旧缺密钥失败状态可迁移为正常账号状态，真实远端冲突不得被此迁移清除。新设备／重装／重登／后台同步须覆盖无恢复材料回归。
- 旧密文只能在持有对应既有材料的设备成功解密并完整验证后，按远端版本 CAS 转为 direct，并校验回读版本／hash。迁移不上传本机可能过期的替代副本，不改变消息事实。无法解密的记录保留原样，提示原设备升级后读取／同步一次，不阻断其他记录。
- 远端修订变化时先读取并验证，再合并完整消息并集，按最新内容及乐观版本提交、回读；不是见到不同版本就永久停在冲突。提交结果 UNKNOWN 先核对，不盲目重复提交。
- 本协议没有逐消息删除凭据；云端缺少消息不代表用户删除，不得清掉本机已有回答。显示末节点不得从完整回答回退到其祖先问题而隐藏保留内容。真正删除对话沿既有对话删除流程处理。
- 历史 Desktop 同 ID 多工作区副本可在读取/上传时补齐缺失消息；必须同时核对稳定对话 ID、消息 ID、角色、父节点及已有正文，排除其他账号回执所属副本，不按标题匹配，不覆盖当前副本已有字段。没有可核对的源数据时不得编造恢复内容。

## 界面

- 账号页“读取云端列表”双端均使用填满卡片可用宽度的长条圆角按钮；图标紧邻文字，两者作为一组居中。删除重复的 HTTPS／恢复保护说明小字；异常结果仍明确展示。

### 云端列表读取边界

- Desktop 侧栏保留“本地／云端”切换：本地页只显示本机对话；云端页只显示读取到的云端对话。读取云端、打开云端行或云端置顶不得替换、隐藏或修改本地页的行与本地置顶；云端行仍走原有打开路由和独立云端置顶。
- “读取云端列表”拉取当前账号完整清单、验证并合并到本机、刷新列表；兼容期可迁移已完整验证的旧密文。每条迁移独立失败，不上传本机内容、自动裁决标题或上传置顶。结果区分已读取与待处理，不把部分成功显示成整批失败。
- 列表使用单 JSON `nanfeng_sync_inventory` 返回条目和总数，避免 PostgREST 行上限静默截断。总数不匹配、超过 10,000 条或 32 MiB 时明确拒绝，不按不完整列表清理回执。该上限是当前支持边界，不是分页性能承诺。
- Android 复用列表 RPC 已返回的完整封包恢复对话和列表置顶，不丢弃封包后再逐条联网读取。单会话明确恢复仍可单独读取；每份封包仍经过绑定、校验和 wire 验证。
- Desktop 在后台线程执行网络与 SQLite 恢复，不占用同步 Tauri 命令的前台执行路径；前端同一时刻只发起一次列表读取。成功条目先显示，不等待账号信息刷新或整页工作区刷新。
- Desktop 逐文档恢复失败不得提前结束整批；回执提供 `failedCount`，界面明确报告部分失败并保留已有条目，不能将部分失败显示成“没有会话”。整个列表 RPC／认证失败仍是读取失败。快速连接／服务暂不可用最多重试一次；鉴权、限流、协议错误、长超时和写入不自动重试。
- 历史恢复工作区已有正文但缺回执时，按当前账号与文档派生的确定工作区身份核对、合并并补回执；不能仅凭旧 package hash 返回成功而使云端列表漏项。
- 正文、模型用量和同步回执在同一事务中写入；拒绝或异常必须回滚，网络等待在事务外完成。账号切换后旧请求不得应用到新账号。
- 手机提示参考 Desktop：白色圆角卡片、居中图标／加粗标题／说明、最大 340dp，不拉成整屏宽条；部分成功用待处理提示，异常说明保留 8 秒，避免与页面底部重复显示。
- 此规则不等同分页或大库性能已验收。当前全封包列表、Desktop 同源副本扫描和工作区 JSON 合并仍需隔离量测；实际双端安装、真实网络和用户大库验证单独记录。

### 已选对话删除与云端列表成员

- 已选对话在本机软删除或永久删除后，续同步清理对应云端文档，不上传删除后的空内容。Desktop 删除与待同步任务同事务保存（沿用现有持久任务 owner）；Android 沿用业务变化触发的已选同步任务。删除失败保留回执供核对／重试，不以网络错误假装已经清理。
- 已有成功同步回执、当前远端明确不存在时，视为该云端副本已被删除：停止续同步，清除当前账号的失效回执／非 UNKNOWN 待同步任务，不按首次上传重建。续同步入口必须要求仍有选中身份；用户再次明确手动同步才可以新建。
- 只有完整、当前账号、各文档身份可判定的列表才可按缺失项清理旧回执和缓存行。空列表是有效的完整结果；RPC 失败、身份变化、无法识别文档、部分恢复结果都不能充当空清单。云端仍存在但因标题冲突等未恢复的条目保留。
- 对照网络请求之前的回执快照，只清理期间没有更新的缺失身份，保留同期新增／更新的选择；账号隔离，不动其他账号回执。云端删除只移除另一端的云端列表／续同步身份，不删除另一端本机正文。
- Android 删除先核对当前远端版本再 CAS 删除，远端已缺失等同删除目标已达到；旧回执版本不能导致永久重复失败。Desktop 同样使用现有核对／删除 owner。仍使用服务端既有逐文档 CAS，不新增全账号清空操作。
- 上述防复活要求参与设备升级到支持该规则的版本；旧客户端仍可能将缺失文档重新上传。没有历史来源的孤立云端文档不得按标题或相似内容自动删除。

### 标题事实与续同步

- 标题属于用户会话事实，不按模型名称、前缀、长度或显示列表猜测或重写。两端保留原始标题，列表只做单行省略展示。
- `titleRevision` 是独立于会话 `revision/updatedAt` 的可选正整数逻辑版本。只有明确改名或自动标题写入推进；置顶、归档、正文、金额更新不推进。读取、上传、保存与再次上传原样保留该字段，不用设备时间判断版本化标题的新旧。
- 标题版本较大者优先；版本相同且标题不同是并发冲突，不静默选某端。双方都是无标题版本的旧记录且标题不同，也不得借用会话时间猜先后。明确保存用户选定标题会创建下一标题版本。迁移保留旧值及 null，不编造历史编辑顺序。
- 新旧格式并存时，有明确标题版本的一方优先于无版本快照；双方已升级后适用完整协议。旧 Android 的严格 wire 读取器可能拒绝新字段；双端必须使用支持该字段的版本，不能承诺未升级客户端正确参与。服务端文档 CAS 只是提交并发门，不是标题新旧裁决者。
- Android 在 domain／Room 写入持有标题版本，并由既有持久任务续同步已选对话。Desktop 手动改名、自动标题、撤销／重做与 `TITLE_PENDING` 任务在同一 SQLite 事务保存；退出重开仍可读取任务。未选会话不入队；后台仅处理当前账号仍在已选回执中的身份。
- Desktop 待同步任务按启动／30 秒唤醒读取，失败退避，UNKNOWN 先核对；标题冲突等待明确新操作，不反复覆盖。完成回执只清除同一标题标记，不清除上传期间发生的新改名。此任务与用户开启的 12 小时全量已选刷新分离。
- 双端合并的共同验收数据为 `protocol/fixtures/title-sync-v1.json`；共同用例通过不替代正式双端设备验收。保存成功、云端确认、列表回读分别报告。

- 账号页复用南枫 AI 现有白卡、字体、圆角、主题色、共享开关和点外关闭规则，分为身份、账号管理、对话同步和云端会话四区，不新建独立视觉风格。“切换 Google 账号”和“退出登录”在账号管理白卡内使用同一灰色填充底、无描边、同轮廓与同反馈，不使用白底描边按钮。
- 账号入口位于设置“数据管理”首行；对话入口只位于既有长按菜单，不在 Composer 新增常驻按钮。

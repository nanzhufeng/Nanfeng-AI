# Desktop 语音转写 Android 对齐矩阵

> 范围：本文只描述 `NanfengTranscriber-Android` 当前源码已经存在的语音转写能力，以及它们迁移到 `Nanfeng_AI/desktop` 时的桌面化转换。`Nanfeng_AI` 现有“南枫转写（GLM-OCR）”仍是图片／PDF → Markdown 的文档转写能力，不改名、不合并为 ASR。

> **状态：历史兼容合同。** 当前 `Nanfeng_AI` C-10 产品行为只读取 [Android 南枫转写当前界面合同](ANDROID_TRANSCRIPTION_UI_CURRENT_CONTRACT.md)。本文只解释已存在的旧音频／视频任务为何继续可读，不授权恢复新建、设置、重试或录音入口。

| 能力 | Android 当前事实 | Desktop 本增量 | 状态／边界 |
| --- | --- | --- | --- |
| 输入 | 文件、分享、文件夹中的音频／视频 | 原生文件选择；按扩展名、普通文件、非符号链接、大小与媒体时长做门禁；没有旧工作区时自动使用不进入普通列表的本地转写空间 | Android 当前没有录音入口，Desktop 不伪造录音，也不要求先导入旧工作区 |
| 格式 | AAC、FLAC、M4A、MP3、OGG、OPUS、WAV、WMA、3GP、AVI、M4V、MKV、MOV、MP4、MPEG、MPG、WEBM | 保持同一扩展名集合；运行前由 `ffprobe`／`ffmpeg` 验证并解码 | 解码器缺失必须进入可恢复失败，不能假装完成 |
| 任务 | Room 持久化队列、取消、失败重试、恢复 | SQLite 持久化任务、进度、分段、取消、失败重试；启动时把中断中的任务转为 `RECOVERY_REQUIRED` | Android 当前没有暂停任务，Desktop 不伪造暂停 |
| 云端模型 | Qwen3-ASR API，固定端点与模型，Key 安全存储 | 复用 Desktop 现有 QWEN Key owner；固定 `qwen3-asr-flash` 适配器，按 5 分钟切片 | 未配置 Key 时等待配置；没有真实请求证据前不写“已实测” |
| 本地模型 | SenseVoice Small INT8 + sherpa-onnx 候选 | 在设置中保留可见但禁用 | **验证中／保留实验**；Desktop 引擎和许可未完成，不可选、不回退伪完成 |
| 语言 | 自动、中文、英文 | 同步三档设置并持久化 | 不增加 Android 未声明的语言 |
| 状态 | 排队、等待输入／模型、准备、转写、导出、需恢复、无语音、完成、失败、取消 | 保持同一用户可见语义 | 错误保存安全提示与技术细节；重试需显式触发 |
| 结果 | 全文、时间轴、原文件预览、复制、TXT／MD／SRT／DOCX 导出 | 结果与分段持久化；复用共享附件预览；原子导出并回读校验 | Qwen 切片只提供切片级时间范围，不伪造词级时间戳 |
| 搜索 | 文件名／正文历史搜索 | 完成任务写入 Desktop 本地搜索索引，结果指向任务详情 | 搜索重建后仍须可恢复，不使用临时内存索引 |
| 继续对话 | 结果可继续用于 AI 工作流 | 将完成的 Markdown 结果作为现有会话附件进入新对话草稿 | 复用共享附件 owner，不复制第二套文件真相 |
| 费用 | Qwen 按音频时长估算 | 保存计费音频毫秒、请求数与人民币微单位估算 | 显示“估算”；不得把本地估算冒充服务商账单 |
| 文件生命周期 | 输入与任务有持久引用 | 输入／结果纳入现有共享附件引用计数、备份与全量本地删除 | 删除任务只释放任务引用；仍被会话引用时不得删字节 |
| UI | 首页创建、任务列表、任务详情、设置 | Desktop 侧栏“南枫转写”入口；灰底画布、亮白卡片；任务与文件动作集中在详情 | GLM-OCR 的 Android 能力与设置保持独立 |

## 最小完整 owner 链

`原生文件选择 → 安全导入共享附件 → SQLite 任务 → 可恢复状态机 → QWEN 凭据／真实执行适配器 → 分段与 Markdown 结果 → 搜索／预览／导出／继续对话 → 共享引用计数与本地备份`

任何环节失败都必须留下可解释的持久状态；构建通过不等于 Qwen、SenseVoice 或真实长音频闭环已验证。

## 2026-09-01 验证快照

- 前端 `114/114`、Rust `120/120`，`0 failed / 0 ignored`；无工作区导入、取消与重试 owner 有独立定向覆盖。
- Browser 在 `1280×800` 和 `480×900` 完成页面、交互边界与无横向溢出检查，console 无 error／warn。
- 唯一 Bundle ID 的 Release Tauri 在全新 `/tmp` 数据根完成真实 WAV 选择、SHA-256 私有复制、任务入库、取消与重启恢复。
- 没有读取 Qwen Key 或发出 Provider 请求；SenseVoice、真实长音频、无语音和四种导出仍属于待真实验收。

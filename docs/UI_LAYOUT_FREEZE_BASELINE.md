# 人工确认 UI 布局冻结基线

状态：**冻结**。本文件记录用户已逐项确认的布局，不是待重新设计的建议。

## 执行规则

1. 新功能可以增加必要界面内容，但只能进入既有信息架构和已有容器槽位。
2. 未经用户新的明确视觉反馈，禁止改变下列已确认控件的位置、尺寸、颜色、层级、圆角、阴影、相邻关系或独立点击面。
3. Domain、Transport、解析、迁移、任务机、持久化、安全、模型服务、验收和测试等底层改动必须保留；不得以“恢复 UI”为由批量回退。
4. 每次涉及 UI 文件的改动，先区分“新增内容”与“既有布局变化”。后者必须在本文件对应条目中获得用户新的明确授权。

## Drawer 底部双控件（Desktop 与 Android 同语义）

权威反馈：`PRODUCT_FEEDBACK_DECISION_LEDGER.md` 的 `FB-P6-051`，以及用户提供的已确认参考效果。

- 设置：底部同一行的**左侧独立白色圆形悬浮按钮**，独立边框和柔和阴影。
- 新对话：底部同一行的**右侧独立紧凑橙色圆角胶囊**，保留方框斜笔图标、居中文本和独立阴影。
- 父容器透明；两个控件不是共同白色 tray、共同卡片、连体胶囊、共享阴影或共享点击区。
- 禁止把新对话拉伸占满横向剩余空间，或把设置改成无底圆形图标。

Desktop 当前实现锚点：

- `desktop/src/chat-shell.mjs`：`chat-sidebar-bottom-actions` 内的 `chat-profile` 与 `new-chat` 两个独立按钮。
- `desktop/src/chat-shell.css`：`.chat-sidebar-bottom-actions` 透明；设置为 `44px` 白色圆形；新对话为 `44px` 高、`22px` 圆角、右对齐的独立橙色胶囊。

## 其他人工反馈基线

- Chat-first 单主面板；手机 Drawer 顺序为搜索、置顶、最近，底部固定设置（`FB-P6-023`）。
- Android 顶部“对话/工作”为单一浅灰分段胶囊，选中项白色浮起且相对整屏水平居中（`FB-P6-052`）。
- Composer 为固定高度、独立阴影的底部 dock；菜单以锚定浮层出现且不得改变 Composer 测量或位置（`FB-P6-056`）。
- Desktop USER 短文本气泡按文字 `fit-content`，不被外层工具或 metadata 撑宽（`FB-P6-063`）。

这些基线只可由用户新的明确视觉反馈替换。

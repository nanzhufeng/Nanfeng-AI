# 南枫 AI Android 当前设置界面合同

日期：2026-08-26
状态：**当前有效；Android 设置首页、二级至四级页面及设置内选择面的唯一视觉／交互正文**

## 1. 范围与冲突处理

本合同定义设置的信息架构、页面层级、用户可见文案、表面材质、暗色皮肤、导航和必要的交互反馈。数据、Provider、凭据、费用、导入、清理和对话 owner 的真实语义仍由各专项合同负责；普通聊天的个性化、Memory 与资料库上下文只以 [Android 当前运行时上下文合同](ANDROID_RUNTIME_CONTEXT_CURRENT_CONTRACT.md) 为准。

`SETTINGS_CENTER_CONTRACT.md`、`P2D_MODEL_SETTINGS_CONTRACT.md` 和历史交接只保留领域边界或验收记录；它们不得重新定义 Android 设置的页面结构、颜色、按钮、图标、弹窗、标题位置或说明文案。若与本合同冲突，以本合同为准。

## 2. 全局页面规范

- 设置是全屏层级导航，不是覆盖在聊天上的长弹窗。设置内的正常入口全部进入下一级页面；仅模型、外观等直接选择值或输入内容时允许使用完整、可关闭、信息不裁切的选择面。
- 设置首页与所有二级、三级、四级页面的最顶部主标题均严格居中，左侧保留返回；首页“设置”使用更大的粗体 `headlineMedium`，不得因左侧返回按钮而左移。暗色皮肤标题与返回图标为白色；浅色为清晰深色。
- 从任意设置二级及以下页面返回其父级时，父级必须恢复离开前的滚动位置；尤其返回设置一级菜单时不得重置到顶部。不同层级各自保留滚动锚点，不能把子页滚动位置误带回父级。
- 浅色：底层为压暗的中性灰，单行入口、按钮和输入框是无描边纯白胶囊；多行信息卡是纯白大圆角。暗色：页面 canvas 和每级页面共享同一深炭灰；前景卡使用较亮炭灰，按钮文字为白，禁止白卡和黑色文字残留。
- 所有白／深卡均去黑线框，不用刻意底部投影。控件仅用留白、表面层级和克制柔影区分。单行白卡、按钮和输入框一律胶囊。
- APP 内全部滑块开关共用明确的 `58×28dp` 实际可见轨道与 `21dp` 圆形拇指；不得继续按历史百分比、默认 Material 尺寸或已变换尺寸推导。必须由共享 `SettingsSwitch` 自行绘制，禁止继续给 Material 3 默认 `Switch` 套外层尺寸；外层可保留 `48dp` 高命中面。关闭态轨道必须是从 `onSurface` 派生的可见浅灰，不能与白色／深色卡面融为一体。普通开关成功切换后只更新滑块和真实本机状态，不弹居中提示、不显示“已保存”行内提示或会话 notice；失败才说明原因。轨道、拇指、按压／水波纹、悬停／焦点反馈与命中面仍必须服从同一胶囊轮廓；不得只改个性化页或某个模型页的局部实例。
- 设置全层级复用主界面的紧凑文字密度：页面标题约 `22sp`、入口与分节标题约 `14–15sp`、正文／说明约 `11–14sp`、标签约 `10–12sp`；字号与行高统一按 Material 基线的 `90%` 缩放，禁止某个子页恢复默认的大号字或只缩字号不缩行高。
- 输入字段标题单独置于输入框上方；禁止 floating label／标题切进输入边框。placeholder 使用明显更浅的辅助色。常规文本按钮为清晰黑／白色，不能灰到像禁用。
- 设置首页入口右侧不显示“进入”或多余箭头；只有可展开的选择控件保留方向指示。删除无行动价值的重复标题、重复小字和风险无关的解释。
- 主题色从“外观”全局注入：选中、开关、保存、强调 icon、点击状态、光标和文本选中不得保留硬编码橙色。模型连接状态、费用金额与加载态、隐私页“已保存在本机”及成功反馈同样使用当前主题色，不得遗留固定墨绿色。抽屉设置图标是中性导航图标，只使用当前正文色，不跟随主题色；“数据管理”分组图标在浅色皮肤使用比正文浅但仍清楚的灰色。
- 图标采用圆端、圆角、近 Q 版语言；提醒图标与关于图标必须不同。外观入口及外观子页使用同一已更新的外观图标。设置首页的“模型与联网”使用节点连接图标（模型服务与联网能力），“导入与导出”使用双向文件流图标，“本机数据”使用本地存储图标；模型与联网、导入与导出不复用通用调节或锁定图标，三者不共享同一图标。

## 3. 设置首页信息架构

首页按大类分组，不使用彩色竖条。默认顺序如下，工作区入口整体置于最后：

| 分组 | 入口（顺序） | 说明 |
| --- | --- | --- |
| 对话 | 个性化、模型与联网、提醒、对话管理 | “模型与联网”固定第二位。 |
| 外观 | 外观、字体大小、强调色 | 显示当前值，不改变触控热区。 |
| 数据管理 | 导入与导出、本机数据、关于 | 不将外观混入本组；分组与子入口不使用重复名称。 |
| 工作区 | 项目与知识、开发与诊断 | 必须位于设置首页最底部，不挤入对话区。 |

首页固定为上述四个组级大卡。每个标题下，将没有说明文字穿插的同组入口收进同一张白色／深色前景卡；相邻行之间使用贯穿整卡、与当前页面 canvas 同色的 `4dp` 横条分隔，不保留分离小卡的外侧间隙。所有这种合并大卡一律使用正常大圆角矩形，禁止胶囊形两端；卡片、分隔条、按压与触控裁切服从同一圆角轮廓。每一行仍保留自身完整点击、按压与无障碍语义；出现错误、提示或需要解释的状态时，单独承载，不夹在普通入口之间。首页只展示这些入口的必要名称和状态，不增加“功能审阅”入口、彩色分组竖条、重复说明或右侧“进入”。

- 二级“工作区”页的“管理 Projects”与“管理知识库”同样合并为一张全宽圆角大卡，纵向单排并以 `4dp` 页面底色横条分隔；入口行为与提示文案不变。
- 二级“开发与诊断”页的“本次 Context 控制”与“离线评测”同样合并为一张全宽圆角大卡，纵向单排并以 `4dp` 页面底色横条分隔；入口行为不变。

## 4. 个性化

- 页面顶部不再重复“个性化”分区标题；右上角放主题色勾号保存，所有编辑先进入草稿，只有点勾后才写入，避免默认保存误改。
- 顶部“启用记忆”开关本身是与其他设置入口一致的单行白色／深色胶囊卡；开关行为不变。卡片下方固定显示辅助说明：“允许 南枫AI 根据你的聊天、文件和已关联的应用为你提供个性化体验。”不显示“已启用”等重复小字，也不显示“保存记忆策略”。“记忆摘要”仍为独立入口，入口下方固定显示：“查看 南枫AI 对你的了解概览。如果你希望它持续记住某些信息，可以使用下方 自定义指令。”
- 普通对话的上下文规则：启用记忆时，昵称、职业与回答偏好作为个性化要求参与每次普通模型调用；非空且已保存的自定义指令是独立的所有对话偏好，即使关闭记忆／个性化也参与每次普通模型调用。全部历史对话是本机原始层；资料库是可追溯的二次整理层。ACTIVE 的全局／当前项目／当前会话 Memory 与资料库命中优先进入本次上下文，原始历史只在资料层不足时补充。不得将全部本地索引无差别外发；暂停／关闭相应开关、超出模型预算、没有相关命中或索引不可用时，该来源不加入。所有检索、排序和预算裁剪发生在本机，只有最终选中的完整片段才随本次请求发送。
- “基础风格和语气”胶囊下方固定显示辅助说明：“这是 南枫AI 在与你对话时使用的主要语气。这不会影响 南枫AI 的功能。”它只解释当前选择的边界，不改变模型、联网或记忆开关。
- “历史资料库”紧跟在“启用记忆”的辅助说明之后，是自动沉淀和普通聊天检索的唯一总开关；不设“高级”分区、折叠箭头、第二个自动开关或额外标题。其 canvas 说明明确：低频整理有价值的历史对话，并在后续对话优先调用少量相关资料；原对话、附件和工具内容不发送，已保存资料可编辑或删除。开关本身即时生效：开启时同时启用自动沉淀和资料库检索，关闭时同时取消后续任务和资料库检索；不得弹出二次确认、成功提示或阻断式说明。范围、模型、Token 与可删除性只保留在页面说明与可审计记录中。关闭不删除已保存资料或原对话；旧版的未确认自动整理状态迁移为关闭，避免升级自动开始外发。
- “记忆摘要”进入独立全屏页面，不以小弹窗呈现。顶部为居中的“记忆摘要”和其正下方更新时间；正文分节标题使用加粗的大标题，正文使用舒适可读的正常字号。右侧溢出菜单提供“关于记忆”“刷新摘要”“删除记忆”“关闭记忆摘要生成和应用”：刷新只回读本机摘要；两个破坏性动作均需各自再次确认，绝不合并。删除只软删除当前摘要，不改变生成／应用开关；关闭只停止后续摘要生成、聊天尾部的“加入记忆摘要”确认和普通对话的相关记忆检索／发送，保留已保存的记忆以及昵称、职业和自定义指令。删除后的软删除记录必须阻止冷启动自动重新写入初始摘要。底部“询问或更新”是独立覆盖在内容之上的悬浮胶囊，只绘制输入框自身的白面与阴影，禁止在底部增加整条白色承托底或为它预留空白区域；提交后必须显式选择“询问摘要”（仅本机查找）或“补充记忆”（才写入本机），不得隐式请求模型或外发内容。默认就载入用户确认的初始摘要，后续只在其基础上增量整理，不能以空白摘要覆盖。
- 记忆写入分两种：
  1. 仅当对未来回答有明显价值的个人事实、偏好、长期计划或决策信息出现时，Assistant 在回答末尾提供一次明确的“加入记忆摘要”确认；频率必须很低，用户不确认不写入。
  2. 用户在对话中输入“记住了”时，结合当前上下文整理其明确要保留的内容，写入记忆摘要并保留可见结果。
- 字段只保留“你的昵称”“你的职业”“自定义指令”。删除“希望如何称呼你”“职业或当前角色”“长期关注方向”“关于你的更多信息”“回答偏好与自定义指令”等旧称。默认自定义指令白色输入区固定为 `5` 行；标题右侧提供克制的 `18dp` 全屏编辑图标（`36dp` 命中面），打开后进入独立全屏长文本编辑面。输入区下方固定显示：“你的 自定义指令 将用于所有南枫AI的对话。”，以紧凑辅助文字说明适用范围。个性化页和全屏自定义指令页保存成功后不显示“已保存至本机”等 Toast、弹窗或行内提示；控件内容已即时反映保存结果，只有失败才在原页面显示可执行错误。全屏页标题居中，右侧为主题色浅底的圆形勾号保存按钮；点击后使用个性化页相同的保存路径写入本机并返回。个性化页右上角保存勾号同样使用圆形框。两种编辑面共用同一草稿和字符上限，关闭全屏仅返回个性化页，不隐式保存。计数器位于自定义指令白色输入区底部右侧，底部留白固定 `5dp`，绝不压住输入正文或留下无效大块空白。
- 用户明确启用个性化并填写“你的昵称”后，昵称作为本机用户资料参与正常聊天；每个新对话的首个成功回复必须先自然称呼该昵称。昵称不因本轮未检索长时记忆而丢失；用户当前消息明确要求其他称呼时，以该要求为准。
- 增加“基础风格和语气”选择，用于调整南枫 AI 对话方式而不改变功能。候选应含默认、专业可靠、亲和友善、直言不讳、高效务实、风趣搞笑等有明确差异的值；“风趣搞笑”可以自然使用轻松幽默，但不得牺牲准确性、清晰度、风险提示或任务结论，严肃／高风险场景保持克制。选择面仅展示名称和简短值说明，不塞入无关功能。此行、外观与强调色三项均为单行白色／深色胶囊：左侧图标（仅外观／强调色）和标题，右侧直接显示当前值（强调色保留小色点），不显示下拉小箭头，不得再用上下两行大卡。

## 5. 提醒与对话管理

### 5.1 提醒

- 页面标题就是“提醒”，删除“通知与提醒”重复标题及说明小字。
- 用户可分别选择：计划监控与对话提醒、对话未读提醒。开关只影响真实存在的提醒；不得伪造通知，不读取或外发对话正文。
- 三项提醒开关统一承托在一张高明度白色大卡内；卡片与灰白页面底形成清晰层级，采用共享大卡圆角和克制短阴影。三行保留各自标题、真实说明与独立开关，以左右 `20dp` 内缩的细分割线分隔；不得再拆成三张独立卡或以空白间距假装分组。

### 5.2 对话管理

- “收藏”“已归档”和“回收站”三个独立入口合并为一张全宽大白卡，并以 `4dp` 页面底色横条分割。收藏只保存本机收藏时间，不会改变正常列表排序、消息、附件或外发边界；收藏页可查看并取消收藏。删除“管理对话”的重复说明段。
- 两个列表的卡片按会话标题（单行、紧凑）和创建时间呈现；不显示重复状态小字。恢复／删除均为滑出操作带，遵循本项目统一的“点带外收起、点删除区才删除”规则。
- 回收站提供永久删除；归档／回收站的恢复、删除都必须具备清晰的确认与结果反馈。进入／返回时使用同一页面底色，避免画面跳变。

## 6. 模型与联网

### 6.1 二级页

- 仅保留四行彩色连接状态：`OpenAI / Claude / Gemini`、`Qwen`、`DeepSeek`、`智谱 GLM`及其“已连接”事实。删除其上方“OpenRouter 已配置 · 当前模型”等灰色行；不得误删这四行状态。
- 连接状态下、模型设置上方固定放置“实时网页搜索”白色／深色圆角卡：左侧使用主题色地球图标，右侧为同一轮廓内的开关。卡片只承托开关的 `48dp` 命中面，使用上下各 `4dp` 内边距（约 `56dp` 总高），不得再以多余内边距拉高。开启说明“需要当前信息时自动检索公开网页并标注来源；可能产生服务费用”，关闭说明“已关闭；普通对话不会使用网页检索”，均单独置于该卡片下方的页面灰底／深色 canvas 上，不并入白卡。开启后仅在新闻、价格、政策、财报、明确要求联网／网页查询等当前信息信号下，使用已实现的当前服务商官方网页检索；“查找附件文档”“找原因”“分析图片”等本地材料任务不得仅因措辞或深度模型选择而附带网页工具。关闭后普通对话（含深度与材料分析）不启用网页工具。此项立即保存本机，不添加聊天页或 Composer 按键。
- 入口固定为：模型设置、费用与用量、上下文记录、运行诊断。模型设置是唯一独立重点卡，以主题色图标和进入箭头强调 API Key、模型与连接；不使用主题色线框或投影阴影。费用与用量、上下文记录、运行诊断合并为标题“调用记录”的单一组合卡，并以卡内横向分隔条区分。所有入口均进入三级页面，不用弹窗。
- 统一调用账本必须包含 GLM-OCR：“费用与用量”的本机累计和上方汇总纳入转写费用，切换栏固定提供第四个“南枫转写”按钮；该分页逐条显示 GLM-OCR 模型、状态、时间、耗时、Token 和可确认的人民币估算。调用详情另沿用服务商、Attempt 和安全失败原因，并从任务 owner 关联原文件名、页数、服务商请求 ID 与安全错误码。文件正文、Prompt、原始请求／响应、Key、URI 与私有路径不得进入设置。
- “费用与用量”统计所有已返回输入、输出 Token 的调用：普通对话、会话标题整理、提醒草案整理、定时监控与历史资料整理；“上下文记录”记录所有回答实际参考的记忆、历史、本地资料、联网资料等；它们不合并。每条 Assistant 回复也可进入同名“上下文记录”，只看该对话／回答的材料，两个入口同名但范围不同。每张记录卡的发生时间固定为辅助小字并右对齐在卡片底部，不插在标题与来源信息之间。
- 运行诊断展示脱敏的调用耗时、失败原因、连接问题、关联会话标题和发生时间。时间与上下文记录共用同一右下角样式；展开技术详情后仍位于整张卡片内容末尾。长原始错误或 JSON 不堆在列表；详情页再按需显示安全摘要。

### 6.2 模型设置三级页

- 此页只管理 OpenRouter、Qwen、DeepSeek、智谱四个服务的 API Key、启用状态、模型和连接；调用记录、费用、上下文、诊断不得混入。DeepSeek 继续使用固定官方端点和同一份本机加密 Key，预设为 `DeepSeek V4 Pro` 与 `DeepSeek V4 Flash`，默认仍为 V4 Pro；智谱使用固定 `https://open.bigmodel.cn/api/paas/v4` 官方端点，聊天预设同时展示 `GLM-5.3` 与 `GLM-5.3 Flash`，两者共用同一份独立加密保存的智谱 API Key，默认仍为 Flash。两个服务都不提供用户可编辑端点或任意模型文本输入。
- “费用与用量”除普通回答外，必须能区分“会话标题整理”“提醒草案整理”“定时监控”和“历史资料整理”四类辅助调用；普通回答每项显示模型、时间、token、人民币金额、实际／估算来源、模型耗时与安全状态。顶部汇总依次展示“本机累计”“会话”“会话标题整理”“历史资料整理”“南枫转写”；五个大类分别使用同规格的全宽前景摘要卡和统一标题层级，每张卡内使用一致的左侧标签、右侧数值行，次数、Token 返回和金额不得再挤成以中点分隔的长句。金额值统一以当前主题色和粗体强调，标签、次数和模型值保持正文／辅助层级；不得因此删减任何统计事实。紧随这些汇总提供白色 `56dp` 分段胶囊，直接点击切换当前明细，当前项用主题色填充和白字，不能使用下拉输入框、箭头或弹出菜单，也不能把不同类型的明细混成一列。提醒草案与定时监控仍作为其他自动任务保留，不得因明细切换而丢失记录。美元等原币金额只在展示层按同一版本化参考汇率换算，换算金额写“约”，本机估算继续写 `≈` 和“估算”；页面只保留一条简洁汇率日期说明，底层原币账本不改写。GLM-5.3 Flash 的人民币价目表按发生时间选择官方限时价或标准价；任何既有记录只要保存了模型、发生时间和输入／输出 Token，读取时即时补算，不改写原始账本。模型耗时仅来自同一条本机请求 Attempt 的“创建至完成”边界；非完成、缺失或不合法边界显示“模型耗时未记录”，不得从消息时间或当前设置推测。辅助调用仍只显示模型、时间、token、人民币金额与安全状态，不显示其输入或输出正文。
- Provider 切换使用居中的单一灰色胶囊轨道，固定顺序为 `OpenRouter → DeepSeek → 智谱 → Qwen`，千问始终排在最后；四项只占一条紧凑分段控件，轨道内边距 `3dp`、选项视觉高度 `32dp`、标签使用 `labelMedium` 单行省略。选中项使用主题色填充和白色文字，未选中项清晰黑／白文字。禁止每个按钮独立白框、黑边或静态橙色，也不得为四项各自做大胶囊而显得拥挤。
- 模型选择显示完整目录名称和 Provider；具体模型名统一使用 `Bold`，Provider、说明和状态仍按原层级。Composer 的短模型名规则及主界面底部正常字重例外不适用于这里。
- API Key 标题在输入框上方，遮蔽状态默认使用足够长的圆点串；不得先显示短串再切换。保存使用主题色，成功时必须可见提示“API Key 已安全保存在本机。”并明确尚未验证连接；保存失败时以同位置的错误卡显示中文原因与下一步，已有配置保持不变。保存不自动发起联网测试，也不保留“已安全保存，输入新值可替换”等无行动价值小字。
- “测试连接”是简洁按钮。点击后必须显示进行中、成功或失败的可理解反馈；请求仅使用固定 `hi` 的实现边界不作为常驻说明小字展示。
- 删除无实际价值或已废弃的质量升级、跨模型复核、保存路由策略、核验模型目录等旧控件与文案。联网能力适用于全部档位和模型，不能只绑定所谓深度档；每个已配置服务商均须在真实请求序列化、来源回传和失败状态中兑现该能力。智谱 `GLM-5.3` 与 `GLM-5.3 Flash` 都使用官方 Chat Completions `web_search` 工具，不能只显示模型入口或说明文字。普通回答调用记录必须保存并显示实际 `glm-5.3`、`GLM-5.3`、智谱接收方、输入／输出与推理 Token、耗时和安全结果；官方响应未给金额且当前中国区直连价目尚未可靠取得时显示金额未知，禁止套用 Flash 或国际渠道价格伪造本机估算。

## 7. 导入与导出、清理与删除

### 7.1 导入与导出

- 顶部“本机数据”概览只保留“对话与内容、附件与导入资料、导入概况”，以正常中文名称同时显示数量和当前实际物理大小；删除“本地记录”“设置与密钥”、API Key 状态及重复说明。图片／视频／音频／文档只统计仍被消息、草稿、知识、临时会话、未完成上传、南枫转写或仍存在的导入对话实际引用的唯一受管文件，并以文件当前长度为准，禁止累计目录表中的历史 `byteCount`。已无有效引用但字节仍在的旧版／中断删除残留必须单列“待清理残留文件”并计入总量，不能继续冒充视频或图片，也不能从总量中隐藏；清理后才从实际占用消失。南枫转写与“已导入附件”是同一附件目录的来源概况，不能在总量中二次相加。导入附件必须读取统一附件目录表，包含仍处于 ZIP 整理阶段且仍有真实 owner 的已归属附件；后台本地检查、模型调用与密钥数据仍由原 owner 管理，不因概览隐藏而删除。
- 概览行只在存在真实明细页时显示右箭头并可点击：“对话”打开搜索“全部”，“消息”打开“正文”，图片／视频／音频／文件分别直达同名搜索分组；搜索范围覆盖所有未删除本地对话，不另建导入导出专用搜索。“知识”与“项目”直达现有知识库和 Projects；“记忆”先进入只包含“记忆摘要”与“个性化与资料库搜索”的统一总入口，两行再进入原有 owner。草稿、其他导入资料和导入批次等没有准确明细页的项仅显示数据，不放箭头、不制造假入口。
- 不再用旧二级菜单把功能藏起来；同页直接分为“对话”和“工作区”。对话区保留两张独立大卡：JSON 对话导入、ZIP 对话导入；工作区与本机备份与恢复各自独立。每张卡的入口纵向单排，以页面底色横条分隔；导入结果不使用胶囊形。
- 对话区：`JSON 导入`和`ZIP 导入`两块各自提供 ChatGPT、Claude 导入入口，并始终显示各自独立的“导入结果”单行入口；入口只保留名称和进入图标，不显示重复统计小字或“查看详情”。即使当前任务表为空，结果入口也不能消失。详情按批次只保留来源、状态、已导入对话数，以及非零的未导入／已跳过数；ZIP 额外保留附件恢复状态、已恢复数和非零的“源包缺少／未关联”数。不得显示正文、标题、原始文件名、推断过程、回退命名、来源记录或个性化资料细节。它们均为正常导入，不称“预检”；删除冗余小字和知识 Markdown／PDF／网页／知识 JSON 导入导出、南枫知识库对话导入。
- 对话 `ZIP 导入`打开系统文件选择器时只请求 ZIP MIME（`application/zip`、`application/x-zip-compressed`），不能用 `*/*` 或泛型二进制 MIME 使各类无关文件看似可导入；选中后仍须走既有私有暂存、大小限制、文件名和 ZIP 目录安全校验。
- 工作区：清晰分为“导入”“导出”“本机备份与恢复”，按钮分别是“导入工作区”“导出工作区”“备份”“恢复”。不得使用“选择完整工作区范围”“选择交换包并恢复”等工程化文案。
- 已有分享满足对话分享需求，删除重复的“导出当前对话”“导出当前文本会话”功能和入口。

### 7.2 清理与删除

- 本页只承担本地数据的删除、清理、失败重试与风险确认；“本机数据”概览和内容钻取固定归“导入与导出”，“清理与删除”不再重复展示。禁止机器表名、夸张阴影和无意义介绍。
- 原始 ZIP 是导入过程的临时来源；只要仍实际保存在 App 私有目录，就必须作为“其他导入资料”按物理文件大小计入本机数据总量一次，但不得把压缩包内每个条目的逻辑解压大小再次累计到图片／视频等分类。页面在删除入口旁提供真实、可行动的状态：任务未完成时提示“请保留 ZIP 原始包”；附件仍依赖 ZIP 时提示“尚未全部内置”并按稳定附件 ID 去重展示依赖数量；所有资料脱离 ZIP 后提示“可以安全删除 ZIP 原始包”；删除完成后提示“导入资料已内置”。页面提供独立的“删除 ZIP 原始包”：先以后台流式 I/O 将所有已归属附件写入正常受管存储并逐项校验，切换稳定附件引用后才能删除；历史中已提交归属关系但附件目录行缺失时，允许仅依据已校验的候选元数据和 ZIP 原字节重建同一附件 ID；原记录指向的旧 ZIP 不在时，可从仍保留的同附件候选中选择哈希和大小完全一致的条目恢复，不得以文件名或 MIME 猜测。任务未完成、任一附件仍依赖 ZIP、缺少可校验原包、哈希／大小不符或中途失败时必须保留全部原包并允许重试。未归属文件随用户确认的原包清理一并移除，不得伪装成已导入附件。
- “导入与导出”已经承担备份／恢复时，“清理与删除”页不得再提供重复的“打开备份与恢复”。
- 清理入口只保留清晰范围：`清空回收站`、`清空已归档`及其真实结果；不得把它们模糊叫作“清空知识与记忆回收站”。其他不可逆清理必须显示准确范围并要求确认。

## 8. 外观、暗色皮肤与选择面

- “外观”是设置首页的独立入口，顺序固定为外观模式、字体大小、强调色。字体大小仅有“小／标准／大”三档，默认“标准”精确保留既有字级；小／大相对标准必须有清晰可见的 `80% / 124%` 差距，选择立即持久化并全局作用于应用文字。与文字并列的信息图标同步以同一比例缩放，字体选择面必须直接预览各档文字与“字体大小”图标；卡片、按钮、触控热区与页面几何不随此变化。
- 强调色当前默认可为橙色，但必须可改变，并立即驱动全局主题令牌、用户气泡派生色、选中态、保存、发送、开关和文本选择颜色。抽屉设置图标明确例外：它始终读取正文色，不随强调色变化。
- 选择面使用完整圆角前景卡，文字与选中勾完整可见。弹层后的 scrim、页面画布、前景卡和文字必须同步适配当前皮肤；深色模式中不得出现白底弹层或黑色标题。
- 皮肤变化需覆盖所有设置层级（一级至四级）、模型设置、导入与导出、清理与删除、归档／回收站、搜索、抽屉和对话，不以设置首页通过作为完成。

## 10. 验收门

- 模型设置的智谱服务必须同时展示聊天预设与独立 `GLM-OCR` 能力说明；GLM-OCR 说明收纳在同一个模型预设选择浮层内，不得在选择框下方另列独立卡片。GLM-OCR 使用同一智谱 API Key，但该信息项不可选择为聊天默认预设，也不得进入 Composer 模型选择。其唯一业务入口“南枫转写”与调用边界读取 [GLM-OCR 南枫转写当前合同](GLM_OCR_DOCUMENT_MARKDOWN_CONTRACT.md)。

- 自动／代码审查：不再有设置弹窗导航、静态橙色、黑边、floating label、右侧“进入”、彩色分组竖条、功能审阅入口、重复导出入口；所有设置层级读同一深色 canvas 令牌。
- 视觉验收：浅／深皮肤均检查设置首页、个性化、记忆摘要、提醒、模型与联网、模型设置、费用／上下文／诊断、归档／回收站、导入与导出、清理与删除、外观选择面。
- 交互验收：个性化必须手动保存；记忆确认与“记住了”路径各自可追踪；测试连接有结果反馈；滑动操作可点外收起；主题色切换同步更新全部强调入口与文本选择。

# 南枫 AI 产品简报

> 状态：已确认的产品基线  
> 更新日期：2026-08-15

## 产品定位

南枫 AI 是“本地数据 + 联网能力”并列的个人多模型 AI 工作台，不存在独立的本地工作区或将本地数据误述为离线隔离。它以 Android 手机作为第一入口，把即时输入、图片、对话和 AI 整理转化为用户拥有、可核对、可追溯、可导出的个人数据与知识资产；后续再扩展到桌面控制中心、Agent 和南枫系软件生态。

南枫 AI 不是单一 Claude 客户端、通用聊天套壳，也不是必须依赖远程 AI Hub 才能运行的前端。

## 核心用户任务

### 第一落点：捕获与知识沉淀

用户在 Android 上输入文字、通过系统分享提交内容或选择图片，确认发送给 OpenRouter 上的实际 Claude 模型；AI 返回结构化整理候选，用户核对或修改后保存为本地知识资产。

成功闭环：

```text
捕获
→ 本地草稿与图片预览
→ 显示 Provider、模型、发送内容和费用提示
→ 用户主动确认
→ AI 整理
→ 用户核对或修改
→ 本地保存
→ 再次读取与导出
```

完成该最小闭环后停止扩充输入类型，立即转入对话主产品。

### 后续核心：Claude 级多模型对话

这是用户后续最需要的能力。目标是达到 Claude 级的流式、分支、上下文、记忆、附件和恢复体验，同时保持 Provider 与模型可替换、调用可追踪、成本透明。

多模型执行固定提供三种同级能力：用户指定目标时使用 Direct；用户要比较差异时使用 Compare，并从首版保留独立分支与后续追问；用户不关心具体目标时才使用 Auto。当前研发优先补齐 Compare 与 Direct 的编排合同，再增强 Auto Router；这不自动改变已经确认的普通对话默认 Auto 入口，也不授权调整既有界面布局。

## 目标用户

- V1：本机单用户。
- 使用场景：随时记录、分享、识图、询问、整理和回看个人信息。
- 长期场景：知识管理、深度生产、Agent 工作流和南枫系应用协同。

## 产品优先级

1. 最小捕获与知识沉淀闭环。
2. Claude 级多模型对话主产品：优先建立 Compare、Direct、Auto 同级编排，研发顺序为 Compare > Direct > Auto。
3. 知识资产浏览、搜索、关联与桌面控制中心。
4. 受控 Agent 自动化。
5. 南枫系软件生态整合与可选 AI Hub。

## V1 产品范围

### 包含

- 原生 Android：Kotlin + Jetpack Compose。
- 文本输入、Android 系统分享和图片。
- 本地草稿、图片私有保存与预览。
- OpenRouter 作为首个真实 Provider，Claude 作为第一测试模型族。
- Provider / Model 预设选择、API Key 本机安全存储。
- AI 结构化整理候选、人工核对、修改和保存。
- 对话、知识、调用安全元数据和用量的本地持久化。
- 最小数据导出协议。
- 捕获闭环后进入流式对话、消息分支、附件、记忆和长上下文。

### 不包含

- 登录、账号中心、多用户与权限体系。
- 云同步、跨设备恢复和远程业务数据库。
- 远程 BFF、远程 AI Hub 与集中 KMS。
- Desktop / Web 客户端。
- 复杂 Agent 工作流。
- 文件、语音、视频和网页解析同时进入首个捕获闭环。

## 数据与信任承诺

- 用户数据默认留在本地；第三方外发必须显式确认。
- 图片先私有保存和预览，AI 结果先进入待核对状态。
- API Key 不进入业务数据库、日志、导出、截图或普通备份。
- 模型、价格和能力不写死，调用记录保存实际 Provider、模型和配置版本。
- AI 不直接决定高风险业务真值，不静默覆盖人工内容。

## 产品成功信号

- 一条真实文本、分享内容或图片可以完成完整捕获闭环。
- 用户始终知道内容将发送给谁、使用哪个模型、可能产生什么费用。
- 保存后的知识保留来源和生成溯源，能够再次读取和导出。
- 捕获闭环完成后，开发重心按计划转入 Claude 级对话，没有被输入类型扩张拖延。
- 对话阶段能够证明切换 Provider / Model 不破坏历史事实和调用记录。

## 实施阶段需实时确定

- 图片以相册选择作为首个实现基线；系统图片分享与拍照在同一数据合同下分别完成权限、取消、临时文件和真机验证后开放。
- 业务数据采用 Room/SQLite，附件采用 App 私有文件目录；具体 Schema、迁移、静态数据加密范围和导出字段在 P1/P2 设计评审中确定。
- OpenRouter 测试 Key、额度和允许使用的非敏感测试资料仍需用户在真实服务验证前单独授权。
- OpenRouter 实时 Claude 目录对应的旗舰、均衡和快速预设，在接入时核验并保留最后可用版本，不写死在本文。
- 完整阶段顺序、未来 Desktop、账号与加密同步、Agent、生态和 AI Hub 边界以 `MASTER_DEVELOPMENT_BLUEPRINT.md` 为总控。

本合同定义南枫 AI 当前 Android / Mac 的行为；跨项目交互与动画的唯一规范在 [UI 基础规范](/Users/nanzhufeng/.codex/skills/design-apps-with-nanfengji-ui/references/ui-foundations.md)。各项目实际落地和设备验收分开记录。

## 范围与所有者

| 平台 / 层 | 唯一职责与入口 |
| --- | --- |
| Android 生成 | 既有 `NormalChatGenerationForegroundService` / WORK 服务执行原请求并保存检查点；展示层不创建、重放或恢复网络请求 |
| Android 元数据 | `GenerationIslandLedger` / `GenerationIslandRuntime` 接服务已提交消息 ID、真实请求模型、SQLite 正文长度与明确终态；UI 不加载整段对话 |
| Android 展示 | `GenerationIslandOverlay` 只负责用户授权后、应用退后台时的悬浮显示；前台完全不显示生成岛，普通操作使用 Toast／准确对象内反馈；系统通知共用任务元数据 |
| Mac 生成 | 既有 Rust 普通聊天 owner；持久化之后更新 `nanfeng_island_v1` 元数据；退出清理按准确 cancellation signal 释放登记 |
| Mac 展示 | 只有独立 `generation-island` 窗口在应用后台使用 `nanfeng-island.mjs` / CSS；主界面不挂载岛。只读取元数据以及打开 / 停止已登记任务。独立窗口不获 workspace、凭据、文件或 Provider IPC 权限 |
| 设置反馈 | 遵从用户最新“打开软件不要显示灵动岛”：前台模型配置保存／连接测试使用对应对象内反馈，通知、外观与个性化使用普通短提示；详细错误保留于对应设置。此前 App 内岛方案已替代 |

CHAT / WORK 的执行、消息与数据根继续隔离；进度键带区域，Android 带本次开始时间，Mac 带本次 assistant 消息 ID。结束后的旧增量不能把任务重新标成运行；显式重试形成新的展示生命周期。

## 状态真相

- 无任务、无操作反馈时不显示岛；不展示低优先级静态说明。
- 请求模型来自本次持久 Attempt / 原生 projection；RC 使用既有短名加 RC，内部实际模型与计费归因不变。
- 未收到已保存正文时显示“等待模型输出”；开始保存正文后显示“正在生成”。不从等待时长猜测深度思考、搜索阶段、百分比、Token、成本或剩余时间。
- 展开显示模型、阶段、已保存正文字符数及耗时。字符数不等于 Token；完成时以最终提交正文为准，允许最终格式归一化后的长度不同于中间流。
- 明确回复提交才显示完成。用户停止显示已停止；系统销毁、未知结果、写入失败或无明确完成事实显示中断。保留原断点与原模型，结果未知不自动重新调用。
- 多对话保持各自身份，紧凑态显示任务数，展开列出各任务及真实可用的查看 / 停止操作；不提供未实现的暂停、继续或 Agent 步骤按钮。

## 展示与生命周期

- 首次出现默认简洁版。旧任务移除／更换生命周期时不得继承旧展开态；回到前台隐藏并收回展开态，再退后台仍以简洁版出现。按统一规范点击顶部切换，点击岛外空白收回简洁版；没有独立“收起”按钮。岛内操作点击不能误触收回；收回只影响展示，不停止生成。
- 成功结果约 2.6 秒，展开阅读成功结果可暂停，收回后重计时。中断／失败／停止最多在终态后展示 3 秒，展开和收回均不暂停、不续期，到期消失；其他仍运行任务继续显示。永久错误与断点仍在原对话中，过期结果不能因新任务或展开复活。
- AI 运行紫色，成功绿色，错误红色，取消灰色，待处理橙色；不靠颜色单独表达状态。
- 同一锚点原位缩放与轻微回弹；快速切换接续当前尺寸，进度只更新文字，不重建按钮、抢焦点或重置滚动。遵从减少动画设置。
- Android 前台不显示任何生成岛；跨 App 显示由设置中的悬浮权限入口明确授权。权限收回、窗口失败、锁屏或屏幕关闭只隐藏岛，不取消服务；未授权仍沿用前台服务系统通知。
- Mac 应用前台完全不显示生成岛；后台／隐藏／最小化窗口使用非激活浮动窗口。前台判断使用 AppKit 应用激活状态和主窗口可见性，应用自身文件选择器失去主窗口焦点不能误判后台。系统鼠标点击其他 App 只触发收回展示，不读取 / 记录按键、坐标或正文，不拦截原点击；事件监听在退出时释放。
- 展示刷新按秒读取元数据；Provider 接收与持久化不依赖任何页面、岛、界面刷新或动画。

## 保活与恢复边界

沿用 [运行时上下文合同](ANDROID_RUNTIME_CONTEXT_CURRENT_CONTRACT.md) 的唤醒锁有限续租、系统活动保护、预览隔离及断点恢复。服务销毁后的任务收尾不重新创建前台通知；Mac 写入异常、提前返回或执行异常都会收口展示并释放本次登记。正常退后台、切页面或打开文件不应额外发出模型请求。

系统强杀、强制停止、断网及系统休眠仍可能结束直连连接；不能保证跨进程死亡仍持续生成。新岛不是服务端持久任务，不扩大 Provider、账号、材料或真实调用授权。

## 功能审阅与验证

当前后台生成与前台普通设置反馈是用户已确认范围，设置“功能审阅”列出用途和现有入口；语音、Agent 步骤和跨 App 任务中心作为待评估方向，不新增常驻按键。此轮没有改动其他 App 的实现。

验证分开报告：领域状态 / 倒计时、真实 Executor + Room 检查点、Rust 登记清理、浏览器组件 / 焦点 / 点击、编译与候选包、原生后台 / 锁屏 / 真实 Provider。浏览器手机视口不等同于 Android 原生验收；独立 Mac 窗口启动也不等于原生后台生成验收。最新结果和未验项见 [PROJECT_STATUS](PROJECT_STATUS.md)，执行证据见当前交接。

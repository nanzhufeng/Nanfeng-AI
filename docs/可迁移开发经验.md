## 通用原则

| 原则 | 复用方法与适用条件 | 本项目证据 |
|---|---|---|
| 当前实现与已提交历史分别建档 | 有WIP时同时清点跟踪与非ignored未跟踪文件，绑定hash、HEAD与执行阶段；全历史统计后读关键提交 | [本轮复盘](verification/2026-10-14-project-retrospective/REPORT.md)、[清单工具](../.agents/skills/nanfeng-ai-document-sync/scripts/inventory_project.py)；大量新owner尚未提交 |
| 持久事实只有一个owner | UI负责投影，输入／后台／网络／失败／重开走同一状态链；边界决定模块，而非页面数 | [AppContainer](../app/src/main/java/com/nanzhufeng/ai/app/AppContainer.kt)、[Desktop普通回答](../desktop/src-tauri/src/desktop_ordinary_chat_v1.rs) |
| 同语义跨平台不等于同实现 | 公共fixture由两端实际owner消费，参数／终态／持久化与重开分别验证；不复制数据库 | [事实fixture](../protocol/fixtures/attachment-report-facts-v1.json)、[双端事实风险](verification/2026-10-14-attachment-fact-risk-review/REPORT.md)、[ADR-002](ADR-002-P6A_DESKTOP_AND_EXCHANGE.md) |
| 外部结果不确定时保留事实 | Attempt／receipt／明确失败与UNKNOWN分开；已返回正文和计量独立保留，先查回执再决定重试 | [P3B](P3B_RUNTIME_EVENT_STATE_MACHINE_CONTRACT.md)、[RC失败计量](verification/2026-10-13-rc-gemini-usage/REPORT.md) |
| 局部工具状态不能代表总任务 | 用最终正常终态及适用证明判定；成功的一次搜索、失败的一次工具调用都不能单独定整个回答 | [DeepSeek真实红绿](verification/2026-10-13-deepseek-terminal-fix/REPORT.md)、[决策](decision-log.md) |
| 计量事实与展示分组分开 | 每物理动作保留币种／身份／价格快照；面向用户按任务分组，未知与已知同时显示，历史不可由当前目录重算 | [费用合同](AI_USAGE_COST_AND_BALANCE_LEDGER_CONTRACT.md)、[七笔原账→两条展示及重开](verification/2026-10-13-retrieval-cost-grouping/REPORT.md) |
| 完成粒度与缓存身份一致 | 一主题的证据不能覆盖全部断言；改变任务粒度时升级指纹、缓存语义，验证旧证据不能误命中 | [v5事实优化](verification/2026-10-14-attachment-fact-granularity/REPORT.md)、[checkpoint](../desktop/src-tauri/src/attachment_search_checkpoint_v1.rs) |
| 迁移与导入是业务行为 | 校验格式／身份／路径／大小／hash，staging→事务/journal→receipt→关闭重开；未知格式不猜配 | [P5D](P5D_LOCAL_BACKUP_RESTORE_DELIVERY_CONTRACT.md)、[Desktop备份owner](../desktop/src-tauri/src/desktop_local_backup_v1.rs) |
| 测试按证据层和成本递进 | 已有安全回执／离线行为回归优先，必要时最小真实样本；同题短答与完整原件分开，失败费用未知不能当零 | [Gemini同题测试边界](verification/2026-10-14-gemini-search-repeat/REPORT.md)、[测试Skill](../.agents/skills/nanfeng-ai-testing-delivery/SKILL.md) |
| 打包、安装、业务验收分别结论 | 精确候选hash、签名身份和数据保持独立核对；同版本覆盖不能只看版本号 | [双端覆盖回执](verification/2026-10-14-fact-risk-cover-install/REPORT.md) |
| 文档只有一份行为权威 | 当前合同、动态交接、决策原因、架构档案、重复流程分别存放；历史章保留日期和锚点 | [合同治理](CONTRACT_GOVERNANCE_CURRENT.md)、[9类冲突裁决](verification/2026-10-14-contract-implementation-unification/REPORT.md) |

这些原则适用于存在持久状态、外部动作、多个入口或平台差异的软件；小型本地静态工具不必照搬全部复杂度。

## 不可直接照搬的部分

- **安全模型**：direct同步不提供端到端加密。不能据此降低目标产品的密钥、合规或服务端信任要求；TLS、鉴权、hash和密文各自保证必须重做威胁分析。[同步SQL](../supabase/migrations/202609180007_p8_account_isolated_sync.sql)。
- **模型与接口**：API ID、Provider、Key组、工具选择、推理预算、倍率、币种与参考汇率都是配置/实际协议事实。品牌或展示名不能作为能力和结算依据；目标部署需重新核验。[架构](model-service/MODEL_SERVICE_ARCHITECTURE.md)、[费用合同](AI_USAGE_COST_AND_BALANCE_LEDGER_CONTRACT.md)。
- **任务预算和解析**：四项一批、48调用/600秒、10分钟检查点及中文标点规则服务于本项目当前执行边界。其他材料、语言、网络或成本要求需要新fixture与预算评估。[coordinator](../app/src/main/java/com/nanzhufeng/ai/ai/AttachmentWebSearchCoordinator.kt)。
- **版本与验收数字**：Schema72、Desktop迁移44、1.0.29、1495/443/551等是带日期快照，不是推荐版本、质量门槛或覆盖率。复用测试结论需核对准确源码与环境。[档案测试节](南枫AI完整开发档案.md#8-测试验证与交付方式)。
- **主设备与产物**：设备ID、bundle ID、证书、私有路径、旧交付授权和截图不能复制到另一软件；同签名也不证明迁移及数据无损。[覆盖报告](verification/2026-10-14-fact-risk-cover-install/REPORT.md)。
- **视觉与入口**：胶囊、主题、字体、隐藏WORK、消息动作和页脚复制是当前产品合同；移植需目标平台输入/可访问性/用户偏好验证。[Android UI](ANDROID_CONVERSATION_UI_CURRENT_CONTRACT.md)、[Desktop UI](DESKTOP_CHAT_FIRST_UI_CONTRACT.md)。
- **外部部署与发布**：仓库SQL、CI定义、构建脚本和本地安装不证明线上服务、Windows或远端Release已交付。[CI](../.github/workflows/source-verification.yml)、[发布策略](GITHUB_REPOSITORY_AND_RELEASE_POLICY.md)。

## 迁移到其他项目的步骤

1. 先列目标入口、数据owner、外部接收方、失败/未知状态和证据层，明确哪些本项目专属假设不成立。
2. 选择一个可观察流程，定义授权、幂等、格式、计量和回读；用目标材料建立失败样本，再做最小实现。
3. 让各端真实owner消费公共fixture并验证重开；只为未覆盖的风险增加必要真实请求，限制费用与重复次数。
4. 维护短AGENTS、独立Skill、唯一领域合同及动态状态；保存当前WIP与历史，不把测试成功扩写为部署完成。

# 附件事实粒度双端风险复核（2026-10-14）

## 范围和发现

针对上一轮事实粒度改动，复核Android／Mac的候选范围、文件身份、隐私、参考URL绑定、任务证据缓存，以及检索调度的失败、取消、UNKNOWN和费用保留边界。本轮不是全软件逐行审查或全部模型真实验收。

| 遗漏风险 | 触发与影响 | 双端修复 |
|---|---|---|
| 开篇事实丢失 | 两个编号章节触发专用planner，首章节前公开事实被跳过 | 保留开篇事实并应用相同完整事实句／隐私过滤 |
| BOM降级解析 | 首个编号标题带BOM，可能未识别专用模式 | 标题识别和正文统一去BOM；仍要求至少两个实际编号章节 |
| 点评链接串项 | 公共事实后只有“点评”标题，再跟参考链接，链接继承前事实 | 评述／评论／点评分隔标题清空来源继承组 |
| “所有数据”断言误删 | 真实数字／日期句以“所有数据”等开头，被宽前缀当核验要求 | 仅识别明确要求核验／查证的控制句，不以该前缀本身判元数据 |
| 多链接粘连 | 同一行两个URL，经OCR空格修复粘成无效网址 | 独立参考URL先分离，随后各自修复空格；URL查询内嵌网址不拆开 |

来源仍需实际transport原生证明；参考URL解析修复不是新增“已核实”依据。报告标题／问候不因包含日期成为事实；标题里的营收等事实线索仍可保留。Rust复用事实／元数据正则，避免每段重新编译。普通材料的参考网址抽取也复用同一函数；来源额度、材料大小上限、模型／Provider／授权接收方、最终原模型回答及费用合并规则不变。行为同步[C12](../../C12_MODEL_NETWORK_PARITY_CONTRACT.md)。

# 附件事实粒度优化（2026-10-14）

## 问题与修复

旧编号报告按章节核验，章节内多个独立事件／数字共用一个状态，整章查询完成不能证明每个断言都有证据。Android与Mac的新planner按完整事实句／分号形成稳定ID；不切逗号、小数点或关联数字，标题及最多96码点段落上下文仅用于定位。每个ID独立返回结论，同句部分支持标未核实。真实来源绑定到公共段落事实组，私密／个人行阻断来源继承。

候选过滤排除纯核验要求；仅出现“公告”的评述不能据此成为事实。检索指令允许同一事件／公告的相关事实共用搜索和来源，缺证事实仍需定向查询。现有四项批次、48调用／600秒上限、UNKNOWN不补发与已完成费用保留规则不变。模型、Provider、Key、正常自身联网、原件最终回答和检索费用合并方式不变。

新版证据指纹为`attachment-fact-evidence-v5`；旧主题回执不命中新版缓存，不回写旧记录，也不触发自动发送。行为唯一正文见[C12](../../C12_MODEL_NETWORK_PARITY_CONTRACT.md)。

# RC 普通文字联网实测与路由建议

日期：2026-10-13。无附件；没有修改业务代码、设置、合同或安装任何应用。

## 结论

普通文字联网并非 RC 全部失效。GPT-6.1 Sol、GPT-6 Astra 建议保留自身搜索；Claude Sonnet 5.5、Claude Opus 5.5、Gemini 3.8 Flash、Gemini 3.1 Pro 建议使用 OpenRouter GPT-6 Luna 搜索助手，再由用户原选 RC 模型回答。该建议尚未写入应用。

| RC 模型 | Android 简单 / 九事项 | Mac 简单 / 九事项 | 建议 |
|---|---|---|---|
| GPT-6.1 Sol | 完成 / 完成；来源补测通过 | 完成 / 完成；来源补测通过 | 保留自身，补来源回传参数 |
| GPT-6 Astra | 通过 / 通过 | 通过 / 通过 | 保留自身 |
| Claude Sonnet 5.5 | 多语言摘要未完整作答 / 无相关结果 | 多语言摘要未完整作答 / 无相关结果 | Luna 助手 |
| Claude Opus 5.5 | 通过 / HTTP 504 | 搜索后正文为空 / HTTP 504 | Luna 助手 |
| Gemini 3.8 Flash | 空正文 / 空正文 | 无搜索证据 / 空正文 | Luna 助手 |
| Gemini 3.1 Pro | 无搜索证据 / 无搜索证据 | HTTP 404 / 无搜索证据 | Luna 助手 |

## 测试与判定方法

24 组基线：六模型 × Android/Mac × 简单问题/九事项问题。另有 Sol 四组来源返回参数对照，以及 Luna 四组同题对照，总共 32 个真实请求结果。没有对 UNKNOWN 请求自动重发。每个模型/平台/难度只有一个基线样本，不能据此保证长期可用率。

简单题为欧盟 AI 透明度公告的发布日期、适用日期与要求；复杂题为诺奖新闻、欧盟法规、美联储政策及微软、英伟达、苹果财报九个公开事项，含故意错误的日期/金额。原始公开问题见 job.json；预先核对的官方答案见 gold.json；逐条结果见 evaluation.json 和 *.result.json。没有发送用户私人原附件。

不能仅以 HTTP 200、工具事件、来源条数或模型声称“已搜索”判断通过。必须同时检查实际搜索证据、可见回答、事项覆盖、关键事实和模型身份。结果里的 nativeSearchPass 只是协议门槛；Sonnet 简单题虽然满足该字段，却未完成用户问题，业务判定仍失败。

## 已定位的差异

1. Sol：四个基线请求都返回真实 web_search 完成事件并完整回答；其中三个未回传结构化来源。临时请求只添加 include=["web_search_call.action.sources"] 后，双端简单/复杂四个对照均回传来源、身份匹配、无事项遗漏。来源候选数量不等于每条都相关或已核验。说明不能把来源回传缺口误判为根本无法搜索。该参数尚未写入应用。官方参数说明：https://developers.openai.com/api/docs/guides/tools-web-search 。
2. Astra：四个基线均有搜索证据、结构化来源和完整回答，复杂题九个编号与预先核对的事实结论均一致。
3. Sonnet：简单题真实工具返回了来源，但最终输出是多语言摘要拼接；复杂题把整段九事项作为单一检索词，返回无相关结果。双端同类失败，不能用有来源图标掩盖任务未完成。
4. Opus：Android 简单题成功；Mac 简单题有来源却没有最终正文；两端复杂题分别约 60.6 秒和 59.3 秒收到 HTTP 504。仅一次成功不足以作为可靠默认搜索路径。504 请求是否产生费用仍未知。
5. Gemini：没有返回可验证的 grounding/search 数据；部分空正文，部分无来源答案，另有 404。未回传 modelVersion，因此实际模型身份也未验证。兼容计费元数据存在 oai_chat 标记，只能提示网关可能发生协议转换，无法据此断言具体哪一层丢失工具。

## Luna 同题对照与费用

四组同题请求全部返回实际模型 openai/gpt-6-luna、服务端搜索次数和完整答案；复杂题均覆盖九项且核对结论一致。简单题 10.9–12.6 秒，复杂题 36.2–43.7 秒。

| 平台 | 问题 | 用时（秒） | 服务端搜索次数 | 服务端报告费用（美元） |
|---|---|---:|---:|---:|
| Android | complex | 43.737 | 7 | $0.07738454 |
| Android | simple | 12.632 | 2 | $0.02193999 |
| Mac | complex | 36.157 | 4 | $0.04566000 |
| Mac | simple | 10.855 | 1 | $0.01111735 |

四次 Luna 请求报告总费用 $0.15610188。这是本轮助手请求费用，不含原 RC 模型再回答的费用。RC 结果保留服务返回的 usage，但没有可统一核对的实际账单金额；不把本地旧价估算冒充实际总消费，也不把失败/未知计为零费用。

Luna 的独立结构化引用 annotations 未返回；正文带 URL 和逐事项来源说明、服务端搜索计数也存在，但这些不等于已取得逐条原生引用映射。因此这里只证明候选助手完成了同题检索与回答，不是原生引用合同已经验收，更不是“Luna 搜索→原 RC 模型最终回答”的完整链路通过。后续接入必须补齐来源映射/核验，再测完整链路。

## 双端覆盖与未覆盖边界

- Android：仅 emulator-5592，在 Android Java runtime 以 shell UID 的 app_process 执行临时 DEX，通过反射加载既有隔离 APK 的 OfficialProviderChatTransport；真实 HTTPS 请求。不是正式应用 UID、界面、AppContainer 或 Room 流程。没有运行 connectedAndroidTest。
- Mac：临时 Rust 原生 reqwest 客户端，复用现有凭据 owner，真实 HTTPS 请求；不是正式应用界面或完整生产传输/对话上下文。
- 直接探测各自接口：GPT Responses/web_search；Claude Messages/web_search_20250305；Gemini generateContent/google_search。不借其他模型成功冒充当前模型自身搜索成功。Claude 探针允许简单 3 次、复杂 12 次工具调用。
- Gemini Mac 探针同时有 Bearer 和 x-goog-api-key，Android 既有传输只设置 Bearer；记录此差异，不声称两端逐字节完全一致。
- 凭据只经原 owner 与内存传递；未写文件、环境变量、参数或输出日志。只保存公开题目的可见回答、来源和 usage，不保存原始响应或推理正文。
- 本轮结论只涉及普通文字问题；不能替代多附件、各类文件、正式应用界面与长期稳定性验收。OpenRouter/官方直连现有规则未动。

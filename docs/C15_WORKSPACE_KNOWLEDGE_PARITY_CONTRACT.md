## 2. 当前权威规则：共用界面，数据独立

本节是 Android／Desktop 工作区与对话区边界的唯一产品正文。入口、存储、上下文、搜索、同步和测试变更均须先读取；旧空态断言或历史截图不得覆盖本节。

### 界面与数据所有权

- 工作页右侧提供正常对话的消息、Composer、附件、模型选择、发送／停止和消息操作，仅左侧导航不同；项目／知识／记忆管理仍有各自页面。未选项目不等于不能对话，真正发送前不得创建假项目或假会话。
- 工作区与对话区的会话数据必须使用独立数据库文件、独立读写归属。组件与无状态执行能力可复用，不因此共享会话列表、消息、标题、草稿、附件引用、上下文或业务状态；不能用同一数据库中的字段／表过滤或隐藏列表冒充此隔离。
- 无项目的工作对话仍属于工作区，绝不因 `projectId=null` 被当作普通对话，也不得退回普通会话集合读取或写入。选中项目后再施加项目边界；失效项目／会话 ID 拒绝解析，不能回退其他范围。
- 搜索、生成上下文、标题任务、续写、同步、备份恢复、删除与回收站均服从所属区域；页面切换、迟到异步结果和后台任务不得把另一范围内容注入当前区。
- 共用 Composer 不能共用可变草稿状态；切换区域分别保存并恢复各自草稿、附件、当前会话与滚动状态，不自动搬运数据。侧栏折叠与展开成对可达，返回原页面恢复原范围。

### 允许人工调用，禁止隐式共享

- 用户可主动从另一区域选择具体会话／消息／资料或附件用于当前任务；必须明确来源、选取范围和接收目标。授权只覆盖所选内容与本次操作，不能扩展为全库读取、后台同步或长期自动检索授权。
- 调用通过受控引用／材料桥进入当前会话上下文，保留来源身份与所选版本；源记录仍归源库，不能合并数据库、移动原会话、共享可变记录或反向覆盖源内容。
- 未选取即不跨区读取；取消选择不外发；后续源内容变化不静默扩张已选材料。附件沿自己的权限和引用生命周期处理，目标删除不得删除源区内容。
- 复用现有材料选择入口，避免新增未经用户判断的常驻按键；真实发送沿既有接收方披露与授权规则执行，不增加重复确认。

### 回归与交付门

- 必须验证两区均能独立新建、发送、回读及重开；两区相同会话 ID、无项目会话、失效项目、切换中的生成和迟到结果均不能串读串写。
- 验证草稿、列表、搜索、标题／费用、上下文与同步范围；删改一区不改变另一区。人工调用测试覆盖未选择／取消无读取、只引入选定内容、有来源、源不变和失败不退回全库。
- 保留“无项目也有完整对话界面”的验收，但不得用普通对话数据库作为通过该验收的捷径；未完成隔离时不能发布或覆盖安装此增量。
- 当前源码：Desktop 请求固定 CHAT／WORK 归属，分别使用 `workspace.sqlite3` 和 `work-area/workspace.sqlite3`；Android 分别使用 `nanfeng-ai.db` 和 `nanfeng-ai-work.db`，Activity、任务和私有文件 owner 同步分区。工作根页共享完整对话组件，无项目也可发送。模型配置与登录身份属于应用配置，不是共享会话库。
- 升级先保留原库快照，再拆分旧 WORK／项目会话及其草稿、消息、调用、同步记录与依赖材料；迁移事务失败保持原库，重开按持久标记回读。历史整库 undo／导入快照留在迁移备份，不再作为活动回滚入口把已分区内容写回另一边。无法核验的结构、冲突独立库或损坏材料拒绝覆盖。
- Desktop 人工调用入口为消息菜单“引用文字到工作区／对话区”（Android 消息长按菜单按用户要求移除此入口）：只复制所选消息文字和来源版本到目标未发送草稿，源不变，不自动发送，不隐式携带附件。资料或附件的扩大选取不由这条文字引用入口授权。
- 跨端同步必须 CHAT↔CHAT、WORK↔WORK；两区使用独立文档身份与云列表，恢复先验区域。协议夹具通过不能代替 Google 真实账号与两台主设备联调。
- **防回退门：** 任何把 WORK（包括 `projectId=null`）写入、读取或恢复到 CHAT，复用同一业务 SQLite，或把 CHAT 作为 WORK 的兜底来源的改动均违反本合同；不得以历史空态、旧 fixture 或列表过滤作为例外。若存储／迁移／同步边界确需调整，必须先更新本节、迁移代码、跨端协议夹具和 Android／Desktop 回归，再允许提交。

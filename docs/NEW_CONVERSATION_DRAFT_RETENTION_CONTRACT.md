- 点击“新对话”恢复本范围未发送的新对话草稿。成功发送后沿既有事务清空；手动删空立即保存。已发送消息和已有会话续聊草稿不受此期限影响。
- 编辑重新计时；读取、切换、重开不续期。到期仅清空文字，附件与源消息不删除；软件关闭期间不依赖后台进程，下一次读取必须先持久清理过期文字，不短暂回显。
- 原文保留换行和首尾空格。异步保存捕获原范围；迟到读取不能覆盖新编辑或另一会话。
- Desktop 使用既有 native SQLite 草稿 owner 和 updated_at_ms；新对话入口不得删除该记录，浏览器缓存不作为持久化真相。Android 使用 Room 草稿 updatedAt；只复用未置顶、未归档／删除、未发送且仍为新对话的记录，并限定 surface 与 project。

- 现有“新对话”与输入框承担交互，不新增常驻按钮。功能审阅结论：保留；理由：短暂离开后继续输入，避免长期残留。

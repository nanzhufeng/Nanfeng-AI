# 南枫 AI Android 当前会话界面合同

日期：2026-08-24
状态：当前 Android 会话 UI 的唯一视觉与交互规则正文

## 1. 适用范围与冲突优先级

本合同只约束 Android `ConversationWorkspace` 的会话画布、顶栏、左侧栏、Composer、模型选择面、消息页脚与短暂文本选择面。它不改变 Conversation/Model/Provider 的领域 owner、真实外发、凭据、费用、导入导出或 Desktop 的规则。

若旧文档中的 Android UI 数值、颜色、布局、手势或弹层行为与本合同不同，以本合同为准；旧条目只保留其历史验收或领域边界。冲突优先级固定为：

1. 本合同：当前 Android 会话 UI 的可见结构与交互。
2. `P6G_MODEL_SELECTION_AUTO_ROUTER_CONTRACT.md`：模型选择持久化、Auto/手动路由与真实归因。
3. `P6F_CONVERSATION_TRANSCRIPT_PRESENTATION_AND_MESSAGE_ACTIONS_CONTRACT.md`：消息、附件、动作和 transcript 的领域语义。
4. `P2D_MODEL_SETTINGS_CONTRACT.md`：设置页服务配置与本机凭据边界。

## 2. 共同材质与层级

- 页面与左栏的底层只使用很浅的无色相中性灰 `#F7F7F7`；前景按钮、会话卡、输入栏和弹层保持白色，以亮度而非色相或硬描边区分层级。
- 常规前景控件不画黑边、刻意边缘线、静态投影或硬阴影；圆角、按压、水波纹和命中面必须使用同一外轮廓。仅系统 scrim 可压暗背景。
- 仅“新对话”保持橙色主动作；选中模型/会话使用低饱和浅橙，不使用高饱和色块。图标与普通文字使用正常深度的中性灰，不能发灰、过黑或抢占正文。

## 3. 顶栏与画布

- 左侧三横线始终显示，且只负责打开侧栏。
- 当前 transcript 非空时：顶栏只保留左侧栏入口、右侧新对话与更多菜单；不得显示居中的“对话 / 工作”切换。
- 空对话时：可显示居中的“对话 / 工作”切换及临时会话入口。该状态不得反向套用到已有内容的会话。
- 主屏对话区使用 Material 标准右滑开启侧栏；不得设置最小距离、角度或其他自定义强制门槛。纵向消息滚动继续由嵌套滚动正常仲裁。

## 4. 左侧栏与会话行

- 左栏列表行的左右边距为 `5dp`、行间距为 `4dp`；会话标题左对齐、绝对日期右对齐，均为单行，不能增加第二行元信息。
- 普通会话行高度固定 `36dp`。标题、日期字号和行高不缩小，只压缩文字上下留白并垂直居中。批量编辑行独立为 `52dp`，不得用批量控件反向拉高普通行。
- 会话行默认不显示快捷动作。仅用户向右滑当前行时露出同高的 `132dp` 三图标操作带；操作带只保留置顶、重命名、删除图标，不显示文字，不增加额外行高。
- 操作带与右侧白色会话卡只用两块 surface 的自然交界区分；不得绘制额外竖线、黑线、圆角独立按钮或阴影。
- 三图标带展开后，点击其图标以外的任意左栏区域（空白、标题、搜索、另一会话、批量编辑、设置、新对话）必须只先关闭操作带并恢复正常行；图标自身仍执行原动作。
- 左栏底部设置为独立白色圆形动作且无硬边/静态阴影；新对话为独立橙色胶囊，二者不共用 tray 或命中区。

## 5. Composer 与模型名

- Composer 的回复对象文本（如“回复 南枫 AI”）与其他信息严格上下居中，不因字体基线而下沉；其文案不被模型名替换。
- 模型显示位于 Composer 右侧，采用固定宽度，不随当前模型自适应。宽度以最长的精简模型名加少量余量为准，当前为 `84dp`；不得保留大段无意义空白。
- 显示名只保留足以区分的详细名称：去掉提供方、`OpenRouter`、中文提示及冗余家族前缀；GPT 系列保留代际，例如 `GPT-5.6 Terra` 显示为 `5.6 Terra`。禁止在 Composer 或消息页脚显示 `(Fast)` 变体。
- 手动选中 `Auto` 时才允许按输入内容执行自动路由；手动选中任何具体模型后，后续输入必须固定该模型。最近一次用户选择必须持久化并作为下次默认，不得每次回到 Auto。
- 标准实时版是可见选择与实际调用的默认；目录中的 Fast 变体必须被拒绝，不以省事的 Fast 回退消耗 token。实际历史归因保持真实，不改写旧记录。

## 6. 模型选择面与短暂弹层

- 模型选择根层和所有二级层均锚定 Composer 模型显示的右缘，右侧对齐；不得因为面板较宽而落到左侧。
- 根层与二级层使用一致的高度规则：内容完整可见，内容结束后仅保留适量底部白区；根层分类的当前项和二级模型的当前项都用相同低饱和浅橙激活。
- 二级层的系统返回、标题返回和向内横滑先回到一级；一级再执行相同返回才关闭整个面。点击任意遮罩空白处始终直接关闭整套模型选择面，不得先退回一级。
- 所有短暂弹层遵循同一返回顺序：有子层时返回子层的上一级，无子层时关闭；外部空白点击直接关闭整个弹层。不得让弹层未关闭时的横滑退出 App。
- 长按文本输入框必须使用白色系统式编辑菜单，至少提供粘贴、全选、自动填充等可用动作；不得仅显示“自动填充”。

## 7. 消息页脚与动作

- 南枫 AI/Assistant 的页脚信息与动作组左对齐；用户侧信息右对齐。模型名直接接在时间之后，不另起一行；不显示“模型：”、中文提示或 `OpenRouter`。
- Assistant 的复制、分享、创建分支图标以创建分支的视觉基准统一；复制和分享不大于分支图标，三者间距紧凑、命中区不重叠，图标颜色为柔和中性灰。
- 消息动作不使用高饱和色、粗黑图标、硬边或独立卡片感；仅在既有允许的消息语义和触发状态下显示。

## 8. 防回归验收

- 自动契约至少锁定：非空/空会话顶栏分流、普通/批量会话行高度、右滑三图标的默认隐藏与同高展开、点外部收起、标准右滑开侧栏、模型面右锚/返回/外点关闭、手动模型持久化与 Fast 拒绝。
- 视觉验收以当前正式包在目标设备的实际页面为准；JVM、构建、签名或安装只证明各自层级，不能替代手势与观感验收。

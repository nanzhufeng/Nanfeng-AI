# 南枫 AI Android 目标设备基准

状态：用户于 2026-08-14 明确提供并要求作为 Android 开发与验收基准。

## 首要实体设备

- 设备：OPPO Find N5
- 外屏物理像素：`1140 × 2616`
- 内屏物理像素：`2248 × 2480`

上述尺寸是目标表面与截图验收基准，不是布局硬编码坐标。Compose 必须使用运行时 `WindowMetrics`、窗口尺寸等级、density、系统栏/安全区、IME 与折叠姿态决定容器；不得用固定像素缩放 Desktop 页面。

## 必须覆盖的设备形态

1. 外屏：单栏主对话、抽屉关闭/展开、Composer 与 IME、附件选择返回、弹层和长内容滚动均无裁切。
2. 内屏：优先利用更宽画布，但仍以对话为核心；导航、对话与可选详情可以自适应分栏，不得出现重复状态所有者。
3. 外屏 ↔ 内屏切换：当前模式、工作区/会话、消息滚动位置、普通/临时草稿、附件草稿、模型 override 和已打开任务按各自 owner 恢复；折叠变化不是重置理由。
4. Activity recreate、进程回收、旋转/多窗口、IME 和系统 picker 返回分别验证，不得以静态截图替代状态连续性。
5. 字体缩放、显示缩放、系统栏和无障碍点击区在两块屏幕上均需复核。

## 证据边界

- `1140 × 2616` 模拟器只能作为外屏近似集成证据。
- 内屏必须另建 `2248 × 2480` 的可控窗口/模拟器证据，并在获得用户授权后以实际 OPPO Find N5 完成最终视觉、折叠切换、OEM picker、性能与安装验收。
- 当前未授权的阶段不得擅自连接、安装、清数据或操作 OPPO；这不影响提前按该设备矩阵设计和自动验证。
- 每次设备证据须记录实际像素、density、窗口 dp、系统栏/IME 状态、应用版本、签名和包哈希，避免只写“手机端通过”。
